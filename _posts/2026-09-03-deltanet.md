## 세 줄 요약

DeltaNet은 새 key-value를 단순히 더하는 대신, 현재 key에 대한 기존 예측 오차만큼 메모리를 수정하는 델타 규칙(delta rule)을 사용한다. 이 논문은 순차적이던 갱신을 generalized Householder 행렬의 compact WY 표현과 UT 변환으로 재구성해, 청크 내부 계산을 GPU 친화적인 삼각 시스템 풀이와 행렬곱으로 바꾼다. 그 결과 DeltaNet을 1.3B와 3B 규모의 언어 모델로 확장하면서도 강한 연상 회상 능력을 유지하지만, 헤드 차원 확장과 길이 외삽에는 여전히 제약이 남는다.

## 이 논문이 풀려는 문제

긴 시퀀스를 처리할 때 softmax attention은 두 가지 비용을 만든다. 학습 계산량은 시퀀스 길이 $L$에 대해 $O(L^2)$이고, 자기회귀 추론에서는 이전 토큰의 key와 value를 저장하는 KV cache가 문맥 길이에 비례해 커진다. 선형 어텐션(linear attention)은 토큰 정보를 고정 크기의 순환 상태에 누적해 이 문제를 피하려 하지만, 단순 누적만으로는 메모리의 내용을 능동적으로 교체하기 어렵다.

기본 선형 어텐션의 상태 갱신은 다음과 같다.

$$
S_t=S_{t-1}+v_tk_t^\top,\qquad o_t=S_tq_t
$$

이 규칙은 새 연관을 계속 더할 뿐, 같은 key 방향에 이미 저장된 내용을 먼저 제거하지 않는다. 시퀀스 길이가 표현 차원보다 길어지면 서로 비슷한 key가 같은 부분공간을 차지하는 충돌(collision)이 누적될 수 있다.

최적화 관점에서도 차이가 있다. 기본 갱신은 온라인 손실

$$
L_t=-\langle Sk_t,v_t\rangle
$$

의 그래디언트 스텝으로 해석할 수 있다. 이 손실의 그래디언트는 현재 예측 $Sk_t$가 정답 $v_t$에 얼마나 가까운지 반영하지 않으므로, 이미 잘 저장된 연관에도 같은 방향의 업데이트가 발생한다. 논문은 이를 연상 회상이나 문맥 내 검색에서 나타나는 약점을 설명하는 직관으로 제시한다. 다만 일정한 그래디언트가 실제 성능 차이를 일으킨다는 인과관계를 입증한 것은 아니다.

DeltaNet은 Widrow–Hoff 델타 규칙으로 이 문제를 다룬다. 다만 기존 DeltaNet의 학습은 시퀀스 방향으로 엄격히 순차적이었다. 상태 $S_t$가 $S_{t-1}$에 의존하므로 GPU의 시퀀스 병렬성을 충분히 쓰기 어려웠고, 대규모 언어 모델로 확장하는 방법도 분명하지 않았다. 반대로 전체 시퀀스를 한 번에 완전 병렬화하면 길이 $L$인 삼각 행렬의 역행렬 계산으로 이어져 $O(L^3)$ 비용이 생긴다.

따라서 이 논문의 핵심 질문은 다음과 같다.

> 델타 규칙의 선택적 메모리 수정 능력은 보존하면서, 학습 계산만 청크 단위의 병렬 행렬 연산으로 바꿀 수 있는가?
{: .prompt-info }

## 선형 순환 모델 계보에서 DeltaNet의 위치

최근 선형 순환 모델들은 대체로 행렬 상태에 외적(outer product)을 더하되, 기존 상태를 어떻게 감쇄하거나 변환할지에서 갈린다.

| 모델 | 상태 갱신의 핵심 | 읽기 |
|---|---|---|
| Linear Attention | $S_t=S_{t-1}+v_tk_t^\top$ | $o_t=S_tq_t$ |
| + Kernel | $S_t=S_{t-1}+v_t\phi(k_t)^\top$ | $o_t=S_t\phi(q_t)$ |
| + Normalization | 상태 $S_t$와 정규화 상태 $z_t$를 함께 누적 | $o_t=S_t\phi(q_t)/(z_t^\top\phi(q_t))$ |
| DeltaNet | $S_t=S_{t-1}(I-\beta_tk_tk_t^\top)+\beta_tv_tk_t^\top$ | $o_t=S_tq_t$ |
| Gated RFA | 스칼라 게이트 $g_t$로 상태와 정규화 상태를 감쇄 | 정규화된 선형 읽기 |
| S4 | 고정 매개변수 기반의 원소별 지수 감쇄 | 상태의 원소별 결합 |
| ABC | key 상태와 value 상태를 별도로 누적 | key 상태에 softmax 적용 후 value 읽기 |
| DFW | $\beta_t\alpha_t^\top$에 의한 원소별 감쇄 후 외적 추가 | $o_t=S_tq_t$ |
| RetNet | 고정 감쇄 $\gamma S_{t-1}$ 후 외적 추가 | $o_t=S_tq_t$ |
| Mamba | 입력 의존적 원소별 감쇄와 입력 주입 | 상태 읽기와 직접 경로 결합 |
| GLA | $S_{t-1}\operatorname{Diag}(\alpha_t)$로 열별 감쇄 | $o_t=S_tq_t$ |
| RWKV-6 | GLA와 유사한 열별 감쇄 | 이전 상태와 현재 value를 함께 읽기 |
| HGRN-2 | 열별 감쇄 후 $(1-\alpha_t)$로 조절된 value 추가 | $o_t=S_tq_t$ |
| mLSTM | forget/input gate와 정규화 상태를 함께 사용 | 안정화된 분모로 정규화 |
| Mamba-2 | 입력 의존적 스칼라 감쇄 후 외적 추가 | $o_t=S_tq_t$ |
| GSA | key/value 상태를 각각 열별 감쇄 | key 상태의 softmax를 이용해 value 읽기 |
| Gated DeltaNet | 전역 게이트와 델타 투영을 결합 | $o_t=S_tq_t$ |

RetNet, Mamba, GLA 계열이 주로 상태 전체나 각 열을 감쇄하는 것과 달리, DeltaNet의 $I-\beta_tk_tk_t^\top$는 현재 key가 가리키는 방향을 선택적으로 수정한다. 이 상태 간 의존성이 회상 능력의 근원이지만, 동시에 GLA처럼 모든 연산을 원소별로 처리할 수 없게 만드는 비용이기도 하다.

## 핵심 아이디어

논문의 전개는 세 단계로 압축할 수 있다.

첫째, 델타 규칙을 generalized Householder 변환으로 본다. 상태에 $I-\beta_tk_tk_t^\top$를 곱하면 현재 key 방향의 기존 정보만 조절할 수 있다.

둘째, 여러 Householder형 행렬의 곱을 compact WY 표현으로 바꾼다. 그러면 매 토큰마다 $d\times d$ 전이 행렬을 구체화하지 않고, $d$차원 벡터 $w_t$와 $u_t$의 외적 합으로 같은 상태를 표현할 수 있다.

셋째, 청크 안에서 순차적으로 정의되는 $w_t$와 $u_t$를 하나의 하삼각 선형 시스템으로 묶는다. 이 시스템을 UT 변환 $T$로 풀면, 핵심 계산이 전진 대입법과 행렬곱으로 바뀐다. 전체 시퀀스에는 순환이 남지만 청크 내부 토큰은 병렬 처리할 수 있다.

모델은 LLaMA 계열 Transformer++의 self-attention을 DeltaNet 레이어로 교체한다. Pre-RMSNorm을 사용하고, 출력 투영 전에도 RMSNorm을 추가한다. FFN은 SwiGLU이며 파라미터 수는 $8d^2$, DeltaNet 레이어는 $4d^2$로 구성해 일반 트랜스포머와 같은 파라미터 할당을 유지한다.

Query, key, value 투영 뒤에는 커널 크기 4의 depthwise-separable short convolution을 둔다. 이후 query와 key에 SiLU를 적용하고 L2 정규화한다. 쓰기 강도는 입력별 스칼라

$$
\beta_t=\sigma(W_\beta x_t)\in(0,1)
$$

로 만든다.

## 방법 — 오차만큼 메모리를 고치는 델타 규칙

### 온라인 회귀 문제로 읽기

DeltaNet이 최소화하는 온라인 회귀 손실은 다음과 같다.

$$
L_t(S)=\frac{1}{2}\lVert Sk_t-v_t\rVert^2
$$

현재 상태가 key $k_t$를 읽었을 때 내놓는 값은 $S_{t-1}k_t$이고, 목표는 $v_t$다. 상태에 대해 한 번의 SGD 업데이트를 적용하면

$$
\begin{aligned}
S_t
&=S_{t-1}-\beta_t\nabla_{S_{t-1}}L_t(S_{t-1})\\
&=S_{t-1}-\beta_t(S_{t-1}k_t-v_t)k_t^\top
\end{aligned}
$$

이 된다. 이를 다시 쓰면

$$
S_t
=S_{t-1}(I-\beta_tk_tk_t^\top)+\beta_tv_tk_t^\top
$$

이다.

$-\beta_tS_{t-1}k_tk_t^\top$는 현재 key 방향에서 읽히던 값을 지우는 항이고, $\beta_tv_tk_t^\top$는 새 값을 쓰는 항이다. 두 항이 함께 있어야 업데이트 크기가 예측 오차에 비례한다. 첫 번째 항을 제거하면 기본 선형 어텐션처럼 새 외적을 계속 더하기만 하므로, 같은 key 방향의 오래된 연관을 교정할 수 없다.

$\beta_t$는 학습률이면서 쓰기 강도다. $\beta_t$가 작으면 기존 기억을 조금만 수정하고, 1에 가까우면 현재 key 방향을 새 value에 가깝게 다시 쓴다.

### L2 정규화가 만드는 투영 구조

논문은 query와 key를 다음처럼 만든다.

$$
k_t=
\frac{\operatorname{SiLU}(W_Kx_t)}
{\lVert\operatorname{SiLU}(W_Kx_t)\rVert_2},
\qquad
q_t=
\frac{\operatorname{SiLU}(W_Qx_t)}
{\lVert\operatorname{SiLU}(W_Qx_t)\rVert_2}
$$

따라서 $\lVert k_t\rVert_2=1$이다. 전이 행렬

$$
I-\beta_tk_tk_t^\top
$$

의 고윳값은 $k_t$에 직교하는 $d-1$개 방향에서 1이고, $k_t$ 방향에서 $1-\beta_t$다. $0<\beta_t<1$이므로 고윳값의 크기는 1을 넘지 않는다.

특히 $\beta_t=1$이라면 $I-k_tk_t^\top$는 $k_t$ 방향만 제거하고 직교하는 나머지 $d-1$차원은 그대로 보존하는 투영 행렬이다. L2 정규화는 단순한 스케일 조정이 아니라 “어느 부분공간을 얼마나 지울 것인가”를 명확하게 만든다. 정규화가 없다면 제거 강도는 $\lVert k_t\rVert_2^2$에도 좌우된다.

## 기본 선형 어텐션의 청크 계산

델타 규칙을 다루기 전에 기본 선형 어텐션을 청크화하면 필요한 구조를 볼 수 있다. 길이 $C$인 $t$번째 청크의 시작 상태를 $S_{[t]}$라 하면 식 (1)은

$$
S_{[t+1]}
=S_{[t]}+V_{[t]}^\top K_{[t]}
\in\mathbb{R}^{d\times d}
\tag{1}
$$

이다. 청크 안의 외적 합을 하나의 행렬곱으로 계산한 형태다.

출력은 식 (2)처럼 두 부분으로 나뉜다.

$$
O_{[t]}
=Q_{[t]}S_{[t]}^\top
+\left(Q_{[t]}K_{[t]}^\top\odot M_C\right)V_{[t]}
\in\mathbb{R}^{C\times d}
\tag{2}
$$

첫 항은 이전 청크까지 축적된 상태를 읽는 inter-chunk 계산이다. 둘째 항은 현재 청크 안에서 과거 토큰만 참조하는 intra-chunk 계산이며, causal mask $M_C$가 미래 토큰의 기여를 제거한다.

단순 가산 규칙에서는 청크 내부 value를 그대로 행렬곱에 넣을 수 있다. DeltaNet에서는 뒤의 토큰이 앞의 토큰이 쓴 값을 수정하므로, 먼저 그 상호작용을 반영한 의사 값(pseudo value)을 구해야 한다.

## 상태를 외적 합으로 다시 쓰기

### 식 (3): 의사 값 벡터

델타 갱신을 전개하면 식 (3)을 얻는다.

$$
\begin{aligned}
S_t
&=S_{t-1}(I-\beta_tk_tk_t^\top)+\beta_tv_tk_t^\top\\
&=\sum_{i=1}^{t-1}u_ik_i^\top
+\beta_tv_tk_t^\top
-\left(\sum_{i=1}^{t-1}u_i(k_i^\top k_t)\right)\beta_tk_t^\top\\
&=\sum_{i=1}^{t}u_ik_i^\top
\end{aligned}
\tag{3}
$$

여기서 새 의사 값은

$$
u_t
=\beta_tv_t-\beta_t\sum_{i=1}^{t-1}u_i(k_i^\top k_t)
$$

이다.

$u_t$는 단순히 $\beta_tv_t$가 아니다. 이전 key와 현재 key의 유사도 $k_i^\top k_t$만큼 앞선 의사 값의 영향을 빼야 한다. 이 보정이 있어야 뒤에서 외적을 단순 합산해도 원래 델타 순환과 같은 상태가 된다.

이 재매개변수화의 이점은 $d\times d$ 상태 변환을 토큰마다 구체화하지 않아도 된다는 데 있다. 대신 $d$차원 벡터의 내적과 외적 합으로 상태를 표현한다. 다만 $u_t$ 자체는 앞선 $u_i$에 의존하므로, 아직 시퀀스 병렬화 문제는 남아 있다.

### 식 (4): 각 기억이 겪는 누적 변환

순환을 완전히 펼치면

$$
S_t
=\sum_{i=1}^{t}
\beta_i(v_ik_i^\top)
\left(
\prod_{j=i+1}^{t}(I-\beta_jk_jk_j^\top)
\right)
\tag{4}
$$

가 된다. 시점 $i$에서 기록한 $v_ik_i^\top$는 이후의 모든 key에 의한 선택적 투영을 차례로 통과한다. 따라서 과거 정보가 단순한 스칼라 감쇄를 받는 것이 아니라, 이후 key들이 정하는 부분공간 변환을 겪는다.

이 식은 DeltaNet의 표현 방식을 보여주지만 그대로 계산하기에는 적합하지 않다. 각 토큰 쌍 사이에 행렬 곱의 누적이 필요하기 때문이다. 논문은 이 식을 전체 길이가 아니라 청크 안에서만 다루고, compact WY 표현으로 압축한다.

## Compact WY 표현으로 청크를 압축하기

$t$번째 청크의 $r$번째 위치 상태를 식 (5)처럼 분리한다.

$$
S_{[t]}^r
=S_{[t]}^0P_{[t]}^r+H_{[t]}^r
\tag{5}
$$

여기서

$$
P_{[t]}^r
=\prod_{j=tC+1}^{tC+r}
(I-\beta_jk_jk_j^\top)
$$

는 청크 진입 전 상태가 청크 안에서 겪는 누적 변환이고,

$$
H_{[t]}^r
=\sum_{i=tC+1}^{tC+r}
\beta_i(v_ik_i^\top)P_{i+1}^{tC+r}
$$

는 청크 내부 토큰이 새로 쓴 정보의 누적이다.

둘 모두 $d\times d$ 행렬이므로 그대로 저장하면 비싸다. 식 (6)은 이들을 외적의 합으로 표현한다.

$$
P_{[t]}^r
=I-\sum_{i=1}^{r}w_{[t]}^i(k_{[t]}^i)^\top,
\qquad
H_{[t]}^r
=\sum_{i=1}^{r}u_{[t]}^i(k_{[t]}^i)^\top
\tag{6}
$$

$w_i$, $u_i$, $k_i$는 각각 $d$차원 벡터다. 이것이 generalized Householder 행렬 곱에 대한 compact WY 표현이다. 큰 전이 행렬을 직접 만들지 않고도 그 작용을 벡터 묶음으로 나타낸다.

이 벡터들의 점화식은 식 (7)이다.

$$
w_{[t]}^r
=\beta_{[t]}^r
\left(
k_{[t]}^r
-\sum_{i=1}^{r-1}
w_{[t]}^i((k_{[t]}^i)^\top k_{[t]}^r)
\right)
\tag{7a}
$$

$$
u_{[t]}^r
=\beta_{[t]}^rv_{[t]}^r
-\beta_{[t]}^r
\sum_{i=1}^{r-1}
u_{[t]}^i((k_{[t]}^i)^\top k_{[t]}^r)
\tag{7b}
$$

$w_r$는 청크 진입 상태가 현재 key 방향에서 얼마나 수정되는지를 나타내고, $u_r$는 청크 내부에서 쓸 새 value를 앞선 key 충돌까지 반영해 보정한다. 두 식의 계수 구조가 같기 때문에 동일한 삼각 변환을 key와 value에 각각 적용할 수 있다.

청크 끝의 상태 갱신은 식 (8)로 정리된다.

$$
S_{[t+1]}
=S_{[t]}
+\left(U_{[t]}-W_{[t]}S_{[t]}^\top\right)^\top K_{[t]}
\tag{8}
$$

$U-WS^\top$에서 $U$는 새로 쓰려는 내용이고, $WS^\top$는 청크 진입 상태에서 현재 key 방향으로 이미 읽히는 내용을 제거하는 보정이다. 이 차이가 델타 규칙의 예측 오차에 해당한다.

출력은 식 (9)다.

$$
O_{[t]}
=Q_{[t]}S_{[t]}^\top
+\left(Q_{[t]}K_{[t]}^\top\odot M\right)
\left(U_{[t]}-W_{[t]}S_{[t]}^\top\right)
\tag{9}
$$

식 (2)와 구조는 같지만 intra-chunk value가 원래 $V$가 아니라 수정된 의사 값이다. 첫 항은 이전 청크의 기억을 읽고, 둘째 항은 causal mask 아래에서 현재 청크의 델타 업데이트를 반영한다.

## UT 변환 — 순차 점화식을 삼각 시스템으로 바꾸기

식 (7)의 문제는 $r$번째 행이 앞선 모든 행에 의존한다는 점이다. 이를 행렬로 묶기 위해

$$
B_{[t]}=\operatorname{diag}(\beta_{[t]}),
\qquad
L_{[t]}
=\operatorname{tril}
(B_{[t]}K_{[t]}K_{[t]}^\top,-1)
$$

를 정의한다. $L$은 strict 하삼각 행렬이므로 미래 위치의 정보는 들어가지 않는다.

식 (10)의 UT 변환은

$$
T_{[t]}
=
\left(
I+\operatorname{tril}
(\operatorname{diag}(\beta_{[t]})
K_{[t]}K_{[t]}^\top,-1)
\right)^{-1}
\operatorname{diag}(\beta_{[t]})
\tag{10}
$$

이다. 그러면 식 (11)은

$$
W_{[t]}=T_{[t]}K_{[t]},
\qquad
U_{[t]}=T_{[t]}V_{[t]}
\tag{11}
$$

이 된다. 부록에서 별도 번호를 받은 식 (12)는 두 번째 관계를 다시 유도한다.

$$
U_{[t]}=T_{[t]}V_{[t]}
\tag{12}
$$

핵심은 일반적인 역행렬을 직접 계산하는 것이 아니라, 단위 대각을 가진 하삼각 시스템을 전진 대입법으로 푸는 것이다. 이후 $T K$와 $T V$는 텐서 코어가 잘 처리하는 행렬곱이 된다. 전체 시퀀스를 한 번에 풀면 $L\times L$ 시스템 때문에 비실용적이지만, 길이 $C$의 청크로 제한하면 계산을 관리할 수 있다. 실무에서는 보통 $C=64$ 또는 $128$을 사용한다.

## 부록의 유도까지 따라가기

### WY 표현의 귀납 구조

부록 B.1은 공식적인 Theorem이나 Lemma 대신 귀납법으로 식 (6)과 식 (7)을 뒷받침한다. 첫 청크에서 $S_0=0$이고, $k_t,v_t\in\mathbb{R}^d$, $\beta_t\in(0,1)$이라고 둔다.

누적 전이 행렬에 대해

$$
P_{n-1}=I-\sum_{t=1}^{n-1}w_tk_t^\top
$$

가 성립한다고 가정하고

$$
P_n=P_{n-1}(I-\beta_nk_nk_n^\top)
$$

에 대입한다. 전개한 뒤 $k_n^\top$을 공통인자로 묶으면

$$
w_n
=\beta_nk_n
-\beta_n\sum_{t=1}^{n-1}w_t(k_t^\top k_n)
$$

가 남는다. 새 행렬 항이 다시 하나의 외적 $w_nk_n^\top$으로 흡수되므로 compact WY 형태가 유지된다.

상태에 대해서도

$$
S_{n-1}=\sum_{t=1}^{n-1}u_tk_t^\top
$$

를 가정하고 델타 전이식에 대입한다. 기존 상태가 현재 key 방향으로 만드는 값을 묶으면

$$
u_n
=\beta_nv_n
-\beta_n\sum_{t=1}^{n-1}u_t(k_t^\top k_n)
$$

을 얻는다. 즉, 두 증명 모두 “귀납 가정을 전이식에 대입하고, 새 key의 전치 벡터를 묶어 다음 보조 벡터로 정의한다”는 같은 논법을 쓴다.

부록의 일부 줄에는 $S_n=\sum_{t=1}^nu_tk_n^\top$으로 인쇄된 표기상 불일치가 있다. 본문 식 (3)과 귀납 전개가 요구하는 형태는 각 항에 대응하는 $k_t^\top$을 쓰는 $\sum_tu_tk_t^\top$이다. 이 글에서는 원문의 불일치를 임의로 새로운 수식으로 해석하지 않고, 본문 식과 증명 구조에 맞는 표기를 사용한다.

### UT 변환의 선형 시스템

부록 B.2는 식 (7)을 행별로 모아

$$
W_{[t]}+L_{[t]}W_{[t]}
=B_{[t]}K_{[t]}
$$

로 쓴다. 따라서

$$
(I+L_{[t]})W_{[t]}
=B_{[t]}K_{[t]}
$$

이고, 양변에 $(I+L_{[t]})^{-1}$을 적용하면

$$
W_{[t]}
=(I+L_{[t]})^{-1}B_{[t]}K_{[t]}
=T_{[t]}K_{[t]}
$$

가 된다. 같은 계수 행렬에서 우변의 $K$를 $V$로 바꾸면

$$
(I+L_{[t]})U_{[t]}=B_{[t]}V_{[t]}
$$

이므로 식 (12)가 성립한다. $W$와 $U$가 같은 $T$를 공유하는 이유가 여기에 있다.

## 완전 병렬 형태가 실용적이지 않은 이유

식 (4)에서 시점 $j$의 value가 시점 $i$의 query에 미치는 가중치를 직접 쓰면

$$
A_{ij}
=
k_j^\top P_{j+1}^{i}q_i
\quad (j\le i),
\qquad
A_{ij}=0\quad(j>i)
$$

이다. 이를 행렬로 정리하면

$$
A=(QK^\top\odot M)T
$$

가 된다.

이 표현은 DeltaNet에도 softmax attention처럼 토큰 간 가중치 행렬을 정의할 수 있음을 보여주므로 RNN 해석에 활용할 수 있다. 그러나 전체 길이에 대한 $T$를 식 (10)으로 구하면 행렬 역연산 비용이 $O(L^3)$로 증가한다. 해석 가능한 완전 병렬 표현이 곧 효율적인 학습 알고리즘은 아니다. 청크 방식은 $T$의 범위를 $C\times C$로 제한하고, 청크 사이에서는 상태만 순환시키는 절충안이다.

## 구현 관점에서

### 학습과 자기회귀 추론의 비대칭

학습에서는 전체 토큰이 알려져 있으므로, 각 청크의 $K K^\top$과 UT 변환을 한꺼번에 계산한다. 청크 내부 출력도 causal 행렬곱으로 병렬화한다. 다만 청크 시작 상태는 이전 청크가 끝나야 정해지므로 청크 사이에는 순차 의존성이 남는다.

자기회귀 추론에서는 한 번에 새 토큰 하나만 들어온다. 이때는 $S_t$를 토큰별 델타 규칙으로 갱신하는 recurrent 경로가 자연스럽다. 논문의 Triton recurrent 커널은 기존 CUDA 커널보다 2배 빠르다고 보고된다.

아래 의사코드는 Listing 1의 계산 흐름을 shape 중심으로 정리한 것이다.

```python
def chunk_delta_forward(Q, K, V, beta, C):
    # Q, K, V: (L, d_head)
    # beta:    (L,)
    # L은 C로 나누어떨어진다고 가정
    L, d_head = Q.shape
    N = L // C

    Q = reshape(Q, (N, C, d_head))
    K = reshape(K, (N, C, d_head))
    V = reshape(V, (N, C, d_head))
    beta = reshape(beta, (N, C))

    B_K = beta[:, :, None] * K       # (N, C, d_head)
    B_V = beta[:, :, None] * V       # (N, C, d_head)

    gram = B_K @ transpose(K)        # (N, C, C)
    L_tri = strict_lower(gram)       # 미래 위치를 제거

    # (I + L_tri) T = I를 전진 대입법으로 풂
    # 이후 오른쪽 beta를 반영한 것과 동등한 변환을 구성
    T = triangular_transform(L_tri, beta)  # (N, C, C)

    W = T @ K                        # (N, C, d_head), Eq. 11
    U = T @ V                        # (N, C, d_head), Eq. 11/12

    S = zeros((d_head, d_head))
    O = empty((N, C, d_head))

    for chunk in range(N):
        q = Q[chunk]                 # (C, d_head)
        k = K[chunk]                 # (C, d_head)
        w = W[chunk]                 # (C, d_head)
        u = U[chunk] - w @ transpose(S)
                                      # (C, d_head)

        o_inter = q @ transpose(S)   # (C, d_head)
        scores = lower_triangle(q @ transpose(k))
                                      # (C, C)
        o_intra = scores @ u         # (C, d_head)

        S = S + transpose(u) @ k     # (d_head, d_head), Eq. 8
        O[chunk] = o_inter + o_intra

    return reshape(O, (L, d_head))
```

원문의 Listing 1은 $S$와 행렬의 전치 방향을 특정 메모리 배치에 맞춰 표현한다. 구현에서는 식 (8), 식 (9)의 차원이 일치하는지 먼저 고정한 뒤, `u @ S`, `S.T @ w`, `u.T @ k` 중 어느 배치를 사용할지 일관되게 정해야 한다.

### 틀리기 쉬운 지점

- `tril(..., -1)`은 반드시 strict 하삼각이어야 한다. 대각까지 포함하면 현재 토큰이 자기 자신을 보정식에 다시 넣어 식 (7)과 달라진다.
- 출력의 causal 행렬은 현재 위치까지 포함하므로 일반 하삼각을 사용한다. UT 시스템과 출력 mask의 대각 처리 방식이 서로 다르다.
- $\beta$는 $K$와 $V$에 같은 방식으로 적용되어야 한다. $W=TK$와 $U=TV$가 같은 $T$를 공유한다는 점을 놓치면 원래 델타 규칙과 등가가 아니다.
- 상태 갱신에 사용하는 것은 원래 $V$가 아니라 $U-WS^\top$이다. $U$만 누적하면 청크 진입 전 상태에서 이미 저장된 예측을 제거하지 못한다.
- query와 key의 L2 정규화는 헤드별 마지막 차원에 적용해야 한다. 모델 전체 차원에 걸쳐 정규화하면 $I-\beta kk^\top$의 헤드별 투영 해석이 깨진다.
- short convolution은 $Q$, $K$, $V$ 선형 투영 직후에 있고 커널 크기는 4다. ablation 결과상 이 연산은 단순한 주변 장식이 아니다.
- 마지막 청크 길이가 $C$보다 짧을 때의 padding과 mask 처리는 추출된 알고리즘에 명시돼 있지 않다. 실제 구현에서는 padded 토큰이 $T$, 상태 갱신, 출력에 기여하지 않도록 처리해야 하지만, 구체적인 방식은 논문에서 확인되지 않는다.
- 다중 헤드에서는 헤드 차원이 128이고 상태는 헤드별 행렬이다. Figure 1의 $d=2048$은 속도 비교 설정이지 모든 실험의 head dimension이 아니다.

## 실험 설정

합성 실험은 세 종류다.

- MQAR은 길이 512, key-value 쌍 64개, 모델 차원 64·128·256·512, 2개 헤드 설정이다.
- MAD는 Compress, Fuzzy Recall, In-Context Recall, Memorize, Noisy Recall, Selective Copy를 포함한다.
- RegBench는 각 입력이 하나의 확률적 유한 오토마타(PFA)에서 생성된 10~20개 문자열로 구성된다. 모델은 문맥에서 기저 언어를 즉석에서 추론하고, held-out PFA가 만든 테스트 시퀀스의 다음 토큰을 예측한다.

언어 모델링에서는 SlimPajama 서브셋과 Mistral tokenizer를 사용한다. 340M 모델은 15B 토큰, 1.3B 모델은 100B 토큰으로 학습한다. 3B 모델은 비교 대상 PowerLM-3B와 같은 설정으로 1T 토큰을 학습한다.

340M과 1.3B 학습은 8개의 NVIDIA H100에서 수행한다. AdamW의 peak learning rate는 $3\times10^{-4}$, initial 및 final learning rate는 $3\times10^{-5}$이고 cosine schedule을 쓴다. Warm-up은 각각 0.5B와 1B 토큰, 배치 크기는 각각 0.5M과 2M 토큰이다. Weight decay는 0.01, gradient clipping 최댓값은 1.0이다. DeltaNet head dimension은 128이고 short convolution 커널은 4다.

1.3B에서는 계산 자원 제약 때문에 convolution을 적용한 DeltaNet만 학습했다. 따라서 해당 규모에서 convolution 유무를 직접 비교할 수는 없다.

## 비용과 트레이드오프

DeltaNet의 학습 효율은 “순환을 완전히 없앴다”가 아니라 “긴 토큰 단위 순환을 짧은 청크별 삼각 계산으로 바꿨다”는 데서 나온다. Figure 1의 $d=2048$, 배치 크기와 시퀀스 길이의 곱이 16384인 조건에서, chunkwise 알고리즘은 $L$과 $d_{\text{head}}$가 커질수록 recurrent 방식보다 더 큰 speed-up을 보인다. 시퀀스 병렬성이 GPU 점유율을 높이고, 행렬곱이 텐서 코어를 활용하기 때문이다.

1.3B 모델의 단일 H100 처리량은 배치 크기와 길이 조합 $2\text{K}\times8$, $4\text{K}\times4$, $8\text{K}\times2$, $16\text{K}\times1$에서 측정됐다. DeltaNet의 속도는 GLA에 근접하고 Mamba보다 현저히 빠르며, 긴 시퀀스에서는 비교된 모든 선형 시간 모델이 트랜스포머보다 빠르다.

경량화 관점에서 주목할 점은 세 가지다.

첫째, 추론 상태가 문맥 길이에 따라 커지는 KV cache와 달리 DeltaNet은 행렬 상태를 유지한다. 그러나 상태가 $d_{\text{head}}$에 대해 행렬이므로, 헤드 차원을 키우는 비용은 작지 않다.

둘째, 완전 병렬화는 $O(L^3)$이어서 사용할 수 없고, 청크 크기 $C$를 통한 절충이 필요하다. $C$가 커지면 병렬 행렬곱의 이점이 커질 수 있지만, 청크 내부 $C\times C$ 삼각 계산과 임시 행렬의 비용도 증가한다. 논문이 주로 64 또는 128을 사용하는 이유를 이 균형에서 읽을 수 있다.

셋째, DeltaNet은 GLA보다 여전히 느리다. GLA의 상태 갱신은 원소별 연산이라 다양한 head dimension으로 타일링하기 쉽지만, DeltaNet은 key 방향을 따라 상태 간 의존성을 축약해야 한다. 선택적 메모리 수정 능력을 얻는 대신 커널 구현 복잡도와 연산 오버헤드를 지불하는 구조다.

## 하이브리드가 보여주는 실용적 선택

논문은 DeltaNet만 고집하지 않고 두 가지 하이브리드를 평가한다.

- Sliding Attention 구성은 DeltaNet과 국소 sliding-window attention을 층마다 번갈아 배치한다.
- Global Attention 구성은 전체 $N$개 층 중 2번째와 $(N/2+1)$번째 층만 global softmax attention으로 교체한다.

340M과 1.3B 결과 모두 두 개의 global attention 레이어가 recall 태스크를 크게 개선한다. 이는 고정 크기 순환 상태가 대부분의 문맥을 압축하고, 소수의 softmax 층이 토큰 간 정밀 비교를 보완하는 구성이다. 다만 이 경우 순수 순환 모델이 제공하는 고정 크기 상태와 계산 특성이 모델 전체에 그대로 유지되는지는 별도의 시스템 평가가 필요하며, 구체적인 추론 비용은 추출본에서 확인되지 않는다.

## 한계와 생각해볼 점

저자가 밝힌 첫 번째 한계는 GLA보다 느린 학습 속도다. DeltaNet은 상태 간 의존성을 모델링하기 위해 커널에서 head dimension 방향의 축약 연산을 수행해야 한다. GLA는 갱신이 원소별이므로 타일링이 더 쉽다.

두 번째 한계는 head dimension과 상태 크기의 확장성이다. DeltaNet의 행렬 상태를 크게 만들기 어려워 1.3B recall 태스크에서 GLA보다 뒤처지는 결과가 나타난다. 델타 규칙이 같은 상태 용량 안에서 더 나은 수정 방식을 제공하더라도, 상태 자체의 용량이 충분하지 않으면 모든 과거 연관을 보존할 수는 없다.

여기에는 병렬성과 표현력 사이의 더 근본적인 절충도 있다. 논문은 기존 연구가 delta rule 자체의 표현력 한계를 보였다고 정리한다. 이를 강화한 recurrent 계열은 더 복잡한 상태 전이를 사용할 수 있지만, 시퀀스 방향으로 병렬화할 수 없다. 따라서 단순히 더 강한 순환식을 택하는 것만으로는 이 논문이 해결하려는 하드웨어 효율 문제를 함께 풀 수 없다.

세 번째는 길이 외삽(length generalization)이다. 논문은 GLA와 RetNet이 학습 길이를 넘어 일반화하고, Mamba도 어느 정도 외삽하는 것과 달리 DeltaNet의 길이 외삽은 제한적이라고 설명한다. 저자들은 DeltaNet에 명시적인 감쇄 인자가 없다는 점이 그 원인일 수 있다고 추측하지만, 이를 입증된 원인으로 제시하지는 않는다.

네 번째는 통계적 불확실성이다. 대규모 모델 학습 비용 때문에 실험을 여러 번 반복하지 못했고 error bar나 신뢰구간을 보고하지 않았다. 따라서 작은 수치 차이, 예를 들어 평균 정확도의 수십 분의 일 단위 차이를 안정적인 우위로 해석하기는 어렵다.

이 논문의 기여를 읽는 핵심은 새로운 순환식 자체보다 계산 표현의 변환에 있다. 델타 규칙은 이미 있었지만, Householder 곱을 compact WY 형태로 바꾸고 청크 안의 점화식을 하삼각 시스템으로 묶으면서 대규모 학습 경로가 열렸다. 반대로 성능 결과는 델타 규칙 하나만으로 softmax attention의 모든 역할을 대체한다고 말하지 않는다. Short convolution과 소수 attention 레이어가 큰 개선을 만드는 결과는 장거리 상태 압축, 국소 위치 처리, 정확한 토큰 비교가 서로 다른 연산을 요구할 수 있음을 보여준다.
